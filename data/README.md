# Data directory

No complete study dataset is stored here.

`outcome_3cls.csv` at repository root is a small sample provided only to show
the expected columns and support smoke tests. The complete outcome descriptions
are third-party Cochrane material and cannot be redistributed by the authors.

For local analyses, place authorized private inputs in the ignored
`restricted_data/` directory or point the variables in `.env` to another
private location. Expected inputs include:

- `outcome_3cls.csv`: three-class dataset;
- `binary.outcome.csv`: original 16-subgroup labels and double-coding fields;
- `leakage_similarity_test_items.csv`: private test manifest generated by the
  leakage audit; and
- retained checkpoint and prediction artifacts.
